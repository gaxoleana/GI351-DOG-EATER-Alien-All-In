# Arcade prototype sprites

Generated with the built-in ImageGen tool. Reference style: existing seal/duck character sprites; crisp chunky 16-bit pixel art, dark outlines and readable silhouettes. These are single idle sprites for a core prototype. Transparent alpha is preserved; source PNGs are copied without image processing. Unity uses Point filtering and sizes the visible alpha bounds to one-cell scale.
